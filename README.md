# BKN: السعودية في عيون الصحافة العالمية

موقع يجمع ما تكتبه الصحافة العالمية عن السعودية وولي العهد، ويترجم العناوين ويلخص المحتوى بالعربي والإنجليزي، ويحلل التغطية.

## الصفحات
| الصفحة | المحتوى |
|---|---|
| **الرئيسية** `index.html` | موجز BKN، والقصص الكبرى، والخبر الأبرز، ومزاج الصحافة، وآخر الأخبار والمقالات |
| **السعودية** `saudi.html` | كل ما يُكتب عن المملكة، مع نبرته ومين يكتب عنه |
| **ولي العهد** `mbs.html` | ما يُكتب عن الأمير محمد بن سلمان تحديدًا |
| **الأخبار** و**المقالات** | بحث، وفلتر حسب المصدر والنبرة والموضوع |
| **التحليلات** `analytics.html` | خريطة العالم، والنبرة يومًا بيوم، وأكثر الصحف والمواضيع، والكلمات الأكثر تداولًا |
| **الأرشيف** `archive.html` | تقويم تختار منه أي يوم، وتشوف موجزه وكل أخباره |
| **التقارير** `report.html` | تقرير أسبوعي يُكتب تلقائيًا، يتطبع أو يتحفظ PDF |
| **العاجل** `breaking.html` | كل خبر يبقى ساعة واحدة، ومعه زر لقالب سناب أحمر |
| **ملفات الصحف** `source.html` | لكل صحيفة: كم كتبت، ونبرتها، ومواضيعها، وآخر ما نشرته |
| **الخط الزمني** `story.html` | لكل قصة كبرى: مين نشر أول، ومين لحقه، وكيف غطّتها كل دولة |
| **متابعاتي** `saved.html` | قائمة المتابعة والمحفوظات |
| **منتج الفيديو** `video.html` | يحوّل أهم الأخبار لفيديو ٩:١٦ (MP4) |
| **الشاشة الكبيرة** `screen.html` | شاشة عرض للمكاتب والمؤتمرات تتحرك لحالها |

## المزايا

**الذكاء الاصطناعي**
- **موجز BKN:** ملخص ليوم السعودية في الصحافة العالمية، يتجدد كل ٣ ساعات
- **القصص الكبرى:** يجمع الأخبار اللي تتكلم عن نفس الحدث في قصة وحدة، ولكل قصة خط زمني
- **تصنيف تلقائي:** الموضوع، والنبرة، وبلد الصحيفة، وهل المادة عن ولي العهد
- **ترجمة للإنجليزي:** كل خبر يُترجم ويُلخّص بالإنجليزي كمان
- **التقرير الأسبوعي:** يُكتب تلقائيًا كل ٧ أيام، ويُنشر في تلقرام

**للقارئ**
- زر **EN / ع** يبدّل الموقع كامل بين العربي والإنجليزي
- **قائمة المتابعة:** تضيف كلمات مثل «أرامكو» أو «نيوم»، والموقع يميّز أخبارها وينبهك أول ما تنذكر. وتنحفظ في جهازك
- حفظ الأخبار، ووضع فاتح وداكن، وينزل كتطبيق على الجوال
- نشرة صوتية، و«الخلاصة في دقيقة»، وتنبيه العاجل

**للنشر والتسويق**
- **قوالب ٩:١٦ للسناب والانستقرام:** قالب **عاجل** بالأحمر، وقالب **خبر** داكن، وقالب **مقال** فاتح، وقالب **موجز**. وفيها كمان مقاس منشور ٤:٥ ومقاس تويتر ١٦:٩
- **منتج الفيديو:** فيديو عمودي MP4 بدقة 1080×1920، فيه مقدمة وأخبار متحركة وختام. تختار المحتوى (أهم الأخبار، الموجز، العاجل، أخبار ولي العهد) والعدد والمدة واللغة
- **الشاشة الكبيرة:** افتح `screen.html` على شاشة تلفزيون، واضغط ⛶ للشاشة الكاملة
- بوت تلقرام، ومشاركة واتساب، وصورة معاينة للروابط

> **عن الفيديو:** يتسجّل داخل المتصفح، فخلّ الصفحة مفتوحة وظاهرة لين يخلص. كروم وإيدج الحديثين يصدّرون MP4 مباشرة. الفيديو بدون صوت، وتضيف الموسيقى من سناب أو انستقرام أو كاب كت.

## خطوات التشغيل على GitHub

### ١) ارفع الملفات
1. أنشئ مستودعًا جديدًا (Repository) واجعله **Public**.
2. اضغط **Add file ← Upload files** واسحب كل محتويات المجلد، ومنها مجلد `.github`.
3. اضغط **Commit changes**.

### ٢) فعّل الموقع
**Settings ← Pages**، واختر في Source: **GitHub Actions**.
بعد دقيقة يصير رابط موقعك: `https://اسمك.github.io/اسم-المستودع/`

### ٣) اسمح للبوت يحدّث الأخبار
**Settings ← Actions ← General**، وانزل لـ **Workflow permissions** واختر **Read and write permissions**، ثم **Save**.

### ٤) أضف مفتاح الترجمة
بدون هذا المفتاح تنجمع الأخبار، لكن تبقى عناوينها بلغتها الأصلية، وبدون ملخصات ولا تصنيف للنبرة والموضوع.
1. سوّ مفتاح من [console.anthropic.com](https://console.anthropic.com). تدفع حسب الاستخدام.
2. في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - الاسم: `ANTHROPIC_API_KEY`
   - القيمة: المفتاح

### ٥) شغّله أول مرة
تبويب **Actions**، ثم **تحديث الأخبار**، ثم **Run workflow**.
بعدها يجيب الأخبار **كل دقيقة** تلقائيًا: كل تشغيل يبقى قرابة ساعة، ويبدأ اللي بعده أول ما يخلص.

## بوت تلقرام: اختياري
ينشر كل خبر عاجل والموجز في قناتك أول ما يوصل:
1. في تلقرام كلّم **@BotFather** وأرسل `/newbot`، وخذ التوكن اللي يعطيك.
2. سوّ قناة، وأضف البوت لها كمشرف.
3. أضف Secret باسم `TELEGRAM_BOT_TOKEN`، وقيمته التوكن.
4. أضف Secret باسم `TELEGRAM_CHAT_ID`، وقيمته معرّف القناة، مثل `@bkn_news`.
5. اختياري: من **Settings ← Secrets and variables ← Actions ← Variables** أضف متغيرًا اسمه `SITE_URL` وقيمته رابط موقعك، عشان ينحط مع كل منشور.

## حسابات X (تويتر): اختياري
عشان يجيب تغريدات واس والعربية عاجل والديوان الملكي ومتحدث التحالف:
1. اشترك في X API من [developer.x.com](https://developer.x.com). الاشتراك مدفوع.
2. أضف Secret باسم `X_BEARER_TOKEN`.
3. تأكد من معرّفات الحسابات في `scripts/sources.mjs` (قائمة `X_ACCOUNTS`).

بدون الاشتراك، يجيب الموقع عاجل واس والعربية من مواقعهم مباشرة.

## سرعة التحديث
| الطريقة | سرعة وصول الخبر |
|---|---|
| GitHub فقط (المجاني) | قرابة دقيقة إلى دقيقتين (جلب كل دقيقة، ثم نشر الموقع في نصف دقيقة تقريبًا) |
| سيرفر + اشتراك X | خلال ثواني |

**للتحديث خلال ثواني:** شغّل السكربت على سيرفر (VPS) بشكل مستمر:
```bash
export ANTHROPIC_API_KEY=...
export X_BEARER_TOKEN=...
WATCH_SECONDS=10 node scripts/fetch.mjs --watch
```
واعرض مجلد المشروع على نفس السيرفر بأي خادم ملفات، مثل Nginx. الصفحة نفسها تفحص العاجل كل ٣ ثواني.

## التعديل
- **اسم الموقع والوصف والساعات**: أول سطور `assets/app.js`
- **الألوان**: أول سطور `assets/style.css`
- **المصادر**: `scripts/sources.mjs`. تقدر تضيف أو تحذف أي صحيفة بسطر واحد
- **كل كم ساعة يتجدد الموجز**: `BRIEF_HOURS` في `scripts/fetch.mjs`
- **مدة بقاء العاجل**: `BREAKING_TTL` في `scripts/fetch.mjs` و`assets/app.js`
